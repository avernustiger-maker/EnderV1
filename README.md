# Ender V1 — FULL CONTENT V1
Target: Minecraft Java 1.21.10 / NeoForge.

Included now:
- Ender Log, Stripped Ender Log, Ender Planks
- Ender Leaves, Ender Glow, Ender Vines
- Enderrite Ore and Enderrite Block
- Ender Fruit and Enderrite item
- Custom 16x16 textures and model/blockstate assets

Compatibility design:
- No direct dependency on EMF, ETF, or Physics Mod Pro.
- Those mods can coexist because this mod uses normal NeoForge block/item registration.

IMPORTANT:
This V1 package is a content-complete ASSET/REGISTRATION BUILD, but not a guaranteed finished gameplay release.
The remaining advanced systems (full wood-family blocks with correct rotation models, Enderrite armor/tools/weapon stats, TNT-only ore conversion/drop, 1-in-10 leaf fruit loot table, tree/world generation, and recipes) require version-specific NeoForge 1.21.10 APIs/data files and should be tested in the exact NeoForge build you use.
